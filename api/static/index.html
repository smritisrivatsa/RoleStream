    How an answer is made

    1. Postings stream inPollers read Greenhouse, Lever and Ashby into Postgres. Debezium and Kafka carry every change to the indexer.
    2. Your question is matchedPostings are split into chunks and stored in Qdrant. A question runs a meaning search and a keyword search together.
    3. A model writes the replyA local 3B model answers from the best matches only, and cites each one.

    The answer comes from a small local model (llama3.2, 3B) and can still get details wrong. Open the posting before you rely on it.
